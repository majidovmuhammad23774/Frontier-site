# 🚜 Armor Thunder (Гром Танков)

Привет! Меня зовут Мухаммад, мне 9 лет. Я сам написал эту игру на HTML, CSS и JavaScript. Это моя гордость!

## 🎮 Об игре
* Битвы с врагами (волны)
* Босс Астроафлефлан (появляется каждые 5 волн)
* Магазин, кейсы, прокачка танков
* Можно играть прямо в браузере!

## 🕹️ Как играть
Открой файл `game.html` в любом браузере.
